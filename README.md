# stay us · 서울 혼캉스 저탄소 가이드

서울여자대학교 바롬종합설계프로젝트 6조 **stay us**의 결과물입니다.
혼자 여행하며 같은 객실을 혼자 쓰면 1인당 숙박 탄소가 구조적으로 커질 가능성이 높습니다.
이 저장소는 그 몫을 조금 더 나은 방향으로 바꾸기 위한 두 가지 도구를 담고 있습니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | **혼캉스 가이드북**: 숙소 고르기, 짐 싸기, 객실 수칙, 채식 식당, 이동, 체크리스트 |
| `passport.html` | **탄소여권**: 여행의 숙박·이동 탄소를 계산하고 실천한 행동을 기록하는 도구 |

## 사용 방법

브라우저로 `index.html`을 열면 됩니다. 별도 설치나 서버가 필요 없습니다.
탄소여권의 기록은 사용자의 브라우저에만 저장되며 어디로도 전송되지 않습니다.

## 계산 기준

- 전력 배출계수: 0.4173 kgCO₂e/kWh (2023년 기준 국가 전력배출계수, 온실가스종합정보센터)
- 객실 전기 기본값: Lee, J. 외 (2024). *Energy and Buildings*, 302, 113735 (투숙 중 평균 0.226kW, 빈 객실 평균 0.176kW)
- 교통수단 배출계수: 영국 정부 DESNZ 2025 온실가스 환산계수 (국내 공식 계수 부재로 차용한 추정치)
- 냉방 온도 효과: 1℃ 상향 시 약 4.7% 절감 (한국에너지공단 발표, 에너지경제 2020.5.22 보도)

모든 수치는 추정치이며, 숙소와 설비에 따라 실제 값과 차이가 있을 수 있습니다. 자세한 출처는 각 페이지 하단에 있습니다.
